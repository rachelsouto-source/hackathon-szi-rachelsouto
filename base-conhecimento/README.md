# Base de Conhecimento — Metodologia de DD Técnica (Seazone)

Metodologia de Due Diligence Técnica desenvolvida por **Rachel Souto** (Lançamentos SZI),
estruturada como base de conhecimento consumível por skills e agentes.

> Este diretório é a **camada de método**. Ele responde *como* auditar um terreno.
> A camada de **memória histórica** (o que já aconteceu nos ~70 empreendimentos da Seazone)
> vive nas abas `aprendizados` e `sintese` da planilha-base, expostas na Nekt, e é
> alimentada pelo repositório `seazone-tech/base-conhecimento-dd-tecnica` — ver
> [`10-consulta-a-base-historica.md`](10-consulta-a-base-historica.md).
>
> As duas camadas se completam: o método diz **o que perguntar**; a memória histórica diz
> **o que costuma dar errado**.

## Como usar

**Como skill / agente:** carregue [`PROMPT-SISTEMA.md`](PROMPT-SISTEMA.md) como prompt de
sistema e deixe os arquivos 00–10 disponíveis como referência a ser lida sob demanda.
O agente deve ler 03 e 04 na íntegra antes de emitir qualquer parecer.

**Como leitura humana:** 00 → 01 → 02 → 03 → 04 é o percurso completo do método.

## Princípio fundamental

> Uma Due Diligence Técnica de excelência não apenas confirma informações —
> ela encontra riscos que ainda não haviam sido percebidos.
